# Анализатор транзакций

## Описание
Приложение для анализа финансовых транзакций из Excel-файлов. Система предоставляет инструменты для обработки данных, генерации отчетов и интеграции с веб-интерфейсами.

## Функциональность
- 📊 **Импорт данных**: Чтение транзакций из Excel-файлов (.xlsx, .xls)
- 🔄 **Экспорт JSON**: Генерация структурированных JSON-данных для веб-страниц
- 📈 **Excel-отчеты**: Создание аналитических отчетов в формате txt
- ⚙️ **Дополнительные сервисы**: Расширенные возможности анализа данных

## Требования
- Python 3.3+
- Библиотеки (см. requirements.txt)
- Excel-файл с транзакциями

### Веб-страницы
Данные для анализа и вывода на веб-страницах — это данные с начала месяца, на который выпадает входящая дата, по входящую дату.

Валюты и акции для отображения на веб-страницах задаются в отдельном файле пользовательских настроек `user_settings.json`.

#### Страница «Главная» `utils.py`, `views.py`
принимает на вход строку с датой и временем в формате
`YYYY-MM-DD HH:MM:SS`
и возвращающую JSON-ответ со следующими данными:
1. Приветствие
2. По каждой карте: последние 4 цифры карты, общая сумма расходов, кешбэк (1 рубль на каждые 100 рублей).
3. Топ-5 транзакций по сумме платежа.
4. Курс валют.
5. Стоимость акций из S&P500.

#### Сервисы `services.py`
- Поиск переводов физическим лицам

Функция возвращает JSON со всеми транзакциями, которые относятся к переводам физлицам.

#### Отчеты `reports.py`
- Траты по категории

Функция возвращает траты по заданной категории за последние три месяца (от переданной даты) за последние 90 дней.
